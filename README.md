Student Form App

A Java Swing GUI application that allows users to fill in student details and display them in a structured format.

Features

Input fields:

Name

Roll Number

Age

Class

Email

Submit button to display the student details.

Clear button to reset all input fields.

Simple and intuitive GUI interface.

Getting Started
Prerequisites

Java JDK installed (Java 8 or later)

How to Compile and Run

<img width="724" height="472" alt="image" src="https://github.com/user-attachments/assets/7788276c-bc1b-47c4-ab25-87ac30055614" />


Open terminal or Command Prompt.

Navigate to the folder containing StudentFormApp.java:

cd path_to_your_project_folder


Compile the Java file:

javac StudentFormApp.java


Run the application:

java StudentFormApp

Usage

Enter student details in all fields.

Click Submit to view the details in the text area.

Click Clear to reset the form.
